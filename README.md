Telangana Weather Data Analysis

The Telangana Weather Data Analysis project focuses on analyzing weather patterns across different
districts of Telangana and understanding how climatic conditions vary throughout the year. The project
aims to identify trends and variations in rainfall, temperature, humidity, and wind speed using interactive Power 
BI dashboards. To present the analysis effectively, four separate dashboards were created: Rainfall Analysis Dashboard
Temperature Analysis Dashboard Humidity Analysis Dashboard Wind Speed Analysis Dashboard

Each dashboard contains multiple visualizations, including:

Clustered Column Charts
Line Charts
Pie Charts
Donut Charts
Matrix Tables
The dataset used for this project was cleaned and validated to ensure data accuracy,
with no null or missing values present in the final analysis.

The primary objective of this project is to understand weather dynamics and identify changing clima
te trends that may impact different sectors.Weather conditions significantly influence agriculture, 
transportation, public health, and daily life. Heavy rainfall can affect farming activities and transportation systems, 
while seasonal weather changes often lead to increased health issues such as flu and viral infections among children and the general public.

By analyzing historical weather data, this project helps in identifying seasonal patterns and district-wise weather variations. 
The insights generated through the Power BI dashboards can support better planning, preparedness, and decision-making for future weather-related challenges.
